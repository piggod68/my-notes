# 字符串

----

## 一、 核心本质：不可变的“字符容器”
字符串是 Python 中最常用的数据类型。你可以把它当成一个**装满了单个字符的只读列表**。

*   **符号**：单引号 `' '`、双引号 `" "`、或三引号 `''' '''`（多行字符串）。
*   **特征**：**有序、不可变（Immutable）**。
*   **代码记忆**：
* 
    ```python
    s1 = 'Hello'
    s2 = "World"
    s3 = """这是多行
    字符串"""
    ```

字符串不可修改



## 字符串的常用方法

==只是用不会修改其字符串本身==



| 方法 | 作用 | 样例 | 返回结果 |
| :--- | :--- | :--- | :--- |
| `find()` | 查找子串，返回**第一次**出现的索引位置，找不到返回 **-1** | `s.find('Python')` | 整数 (索引或 -1) |
| `count()` | 统计子串在字符串中出现的次数 | `s.count('H')` | 整数 |
| `upper()` | 将字符串中的所有字母转换为**大写** | `s.upper()` | 新字符串 |
| `lower()` | 将字符串中的所有字母转换为**小写** | `s.lower()` | 新字符串 |
| `split()` | 将字符串按指定分隔符**分割成列表** | `s.split(' ')` | 列表 (List) |
| `strip()` | 去除字符串**两端**的空白字符或指定字符 | `s.strip()` / `s.strip('*')` | 新字符串 |
| `replace()` | 将字符串中的指定子串**替换**为新的子串 | `s.replace('H', 'C')` | 新字符串 |
| `startswith()` | 检查字符串是否以指定子串开头，返回布尔值 | `s.startswith('P')` | 布尔值 (True/False) |
