# 🐟 大肥鱼私藏：Python 列表 (List) 核心通关秘籍

列表是 Python 中使用频率最高的数据容器。你可以把它当成一个**超级灵活的动态抽屉**。

## 一、 核心特征与定义
*   **符号**：中括号 `[]`，元素之间用逗号 `,` 分隔。
*   **特征**：**有序**（有索引）、**可变**（可增删改）、**啥都能装**（允许类型混合、允许重复）。



	# 🐟 Python 列表 (List) 核心操作：增、删、改、查

## 一、 增 (Add) —— 往抽屉里放东西
 
| 方法         | 语法                    | 作用                       | 示例与结果                                                   |
| :--------- | :-------------------- | :----------------------- | :------------------------------------------------------ |
| **append** | `list.append(元素)`     | **末尾追加**单个元素（最常用）        | `a = [1, 2]`<br>`a.append(3)`<br>结果：`[1, 2, 3]`         |
| **insert** | `list.insert(索引, 元素)` | 在**指定索引位置**强行插入元素        | `a = [1, 3]`<br>`a.insert(1, 2)`<br>结果：`[1, 2, 3]`      |
| **extend** | `list.extend(可迭代对象)`  | **合并**另一个列表（把元素一个个拆开加进去） | `a = [1, 2]`<br>`a.extend([3, 4])`<br>结果：`[1, 2, 3, 4]` |

> ⚠️ **避坑**：`append` 是把你给的东西**当成一个整体**塞进去；`extend` 是把它**拆开**一个个塞进去。

---

## 二、 删 (Delete) —— 把不需要的扔掉

| 方法         | 语法                 | 作用                              | 示例与结果                                                                   |
| :--------- | :----------------- | :------------------------------ | :---------------------------------------------------------------------- |
| **remove** | `list.remove(元素值)` | 删除**指定的值**（如果有重复，只删第一个）         | `a = ['苹果', '香蕉', '苹果']`<br>`a.remove('苹果')`<br>结果：`['香蕉', '苹果']`       |
| **pop**    | `list.pop(索引)`     | 删除指定索引的元素，**并返回被删掉的值**（默认删最后一个） | `a = [10, 20, 30]`<br>`x = a.pop(0)`<br>结果：`a` 变成 `[20, 30]`，`x` 是 `10` |
| **del**    | `del list[索引]`     | 直接根据索引暴力删除（不是函数，是语句）            | `a = [10, 20, 30]`<br>`del a[1]`<br>结果：`[10, 30]`                       |
| **clear**  | `list.clear()`     | **清空**整个列表，变成 `[]`              | `a = [1, 2, 3]`<br>`a.clear()`<br>结果：`[]`                               |

> 💡 **面试常考**：`remove` 是按“值”删，`pop` 和 `del` 是按“位置（索引）”删。

## 三、 改 (Update) —— 替换里面的内容

| 操作 | 语法 | 作用 | 示例与结果 |
| :--- | :--- | :--- | :--- |
| **单改** | `list[索引] = 新值` | 替换指定位置的元素 | `a = ['红', '绿', '蓝']`<br>`a[1] = '黄'`<br>结果：`['红', '黄', '蓝']` |
| **切片改** | `list[开始:结束] = [新列表]` | 批量替换一段范围内的元素 | `a = [1, 2, 3, 4, 5]`<br>`a[1:4] = ['A', 'B']`<br>结果：`[1, 'A', 'B', 5]` |

---

## 四、 查 (Read) —— 把东西找出来

| 操作       | 语法                | 作用                   | 示例与结果                                                                            |
| :------- | :---------------- | :------------------- | :------------------------------------------------------------------------------- |
| **按索引查** | `list[索引]`        | 获取指定位置的元素（支持负数）      | `a = ['苹果', '香蕉']`<br>`a[0]` → `'苹果'`<br>`a[-1]` → `'香蕉'`                        |
| **切片查**  | `list[开始:结束:步长]`  | 获取一部分元素（==包前不包后==）   | `a = [0, 1, 2, 3, 4]`<br>`a[1:4]` → `[1, 2, 3]`<br>`a[::-1]` → `[4, 3, 2, 1, 0]` |
| **查索引**  | `list.index(元素值)` | 查找某个值在列表里的位置（找不到会报错） | `a = ['A', 'B', 'C']`<br>`a.index('B')` → `1`                                    |
| **查次数**  | `list.count(元素值)` | 统计某个值在列表里出现了几次       | `a = [1, 2, 2, 3]`<br>`a.count(2)` → `2`                                         |
| **查在不在** | `元素值 in list`     | 判断元素是否在列表中，返回布尔值     | `a = ['A', 'B']`<br>`'A' in a` → `True`                                          |
