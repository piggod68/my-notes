## Git
---

**1.

概念	含义
仓库（Repository）	                 存放项目文件和所有历史记录的地方
工作区（Working Directory）  你当前能看到、能编辑的文件目录
暂存区（Staging Area）	         准备提交的文件暂时放这里
提交（Commit）	                     一次“存档”，记录这一刻的所有改动
分支（Branch）	                     独立的开发线，默认叫 main 或 master
远程仓库（Remote）	             托管在 GitHub/GitLab 等平台上的仓库

***3.


接下来  就是初始配置把你的名字,邮箱给他
-  Git 需要知道“你是谁”，这样以后你提交代码时，系统才知道是谁改的
-  git config --global user.name "你的名字或昵称"
-  git config --global user.email "你的邮箱@example.com"
