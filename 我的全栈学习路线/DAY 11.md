### 元组

$$ 元组（Tuple）就是刻在石头上的契约
$$ 
### 为什么 Python 要设计一个不能修改的容器？

安全：比如你要存一个数据库连接配置，绝对不想在程序运行中不小心被改掉，用元组就很安全。

速度快：元组在内存里占用的空间比列表小，运行和查找速度也比列表快。

可以当字典的“键”：字典的键必须是不可变的，所以列表不能当键，但元组可以！

----

## 一、 核心本质：上了锁的“只读列表”
元组（Tuple）和列表（List）长得很像，但它是一个**不可变**的序列。
你可以把它当成一个**刻在石头上的契约**，一旦写好，就绝对不能修改。

*   **符号**：小括号==()
*   **特征**：**有序、不可变（Immutable）、允许重复、可以装任意类型**。
*   **核心优势**：比列表更安全、运行速度更快、占用内存更小。

---

## 二、 定义方式（极其重要，新手必看）

### 1. 普通定义
```python
# 创建一个包含多个元素的元组
coordinates = (10, 20)

# 创建一个混合类型的元组（啥都能装）
person = ("张三", 18, 175.5, True)

# 创建一个空元组
empty_tuple = ()
```

-----

## 一、 核心概念：打包快递与拆快递

*   **组包 (Packing)**：把多个散落的值，自动打包进一个容器（通常是元组）。 —— **化零为整**
*   **解包 (Unpacking)**：把容器里的元素，逐个拿出来赋给不同的变量。 —— **化整为零**

---

## 二、 组包 (Packing) —— 你可能一直在用，但不知道它叫啥

在 Python 中，多个值用逗号隔开，**默认就会自动组包成元组**。

```python
# 1. 显式组包
t = (1, 2, 3)

# 2. 隐式组包（最常见！右边会自动打包成元组）
a = 1, 2, 3
print(a)        # 输出：(1, 2, 3)
print(type(a))  # 输出：<class 'tuple'>

# 3. 函数返回多个值，底层也是组包
def get_info():
    return "大肥鱼", 18  # 自动组包成 ("大肥鱼", 18)

```
