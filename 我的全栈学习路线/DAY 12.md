# set

就是去重，没其他新奇的了


## 一、 核心本质：抓娃娃机的“玻璃缸”
集合是一个**无序**、**不允许重复**的容器，它是**去重**和**数学集合运算**的神器。

*   **符号**：大括号 `{}`（注意：里面没有冒号）。
*   **核心特征**：
    1.  **无序**：不能靠索引（`[0]`）去拿东西。
    2.  **唯一**：自动去重，不允许有重复元素。
    3.  **可变**：可以往里加东西、删东西。

---

## 二、 定义
```python
# 1. 普通定义（重复的会被自动删掉）
letters = {"A", "B", "C", "A", "B"}
print(letters)  # 输出：{'A', 'B', 'C'}

# 2. ⚠️ 致命避坑：空集合的定义
empty_set = set()  # ✅ 正确做法
# empty = {}       # ❌ 错误！这是空字典！
```

----

## 三、 基础操作：增、删、查（没有“改”）
因为集合无序，所以没有索引，无法修改某个特定元素。


# 1. 增 (Add)


```python
fruits.add("橘子")              # 增加单个元素
fruits.update(["西瓜", "葡萄"]) # 增加多个元素
```


# 2. 删 (Delete)
```python
fruits.remove("香蕉")       # 删除指定元素（不存在会报错）
fruits.discard("西瓜")      # 删除指定元素（不存在不报错，推荐！）
fruits.pop()                # 随机删除一个元素
fruits.clear()              # 清空集合
```

四、 🌟 核心必学：数学集合运算


- 交集	` & ` 两个班都报了的同学	==a & b
                                    结果：{'小红', '小刚'}
- 并集	` | `	两个班所有的同学（去重）	==a | b
                                    结果：{'小明', '小红', '小刚', '小李'}
- 差集	` - `	只报了 Python，没报 Java	==a - b
                                    结果：{'小明'}
- 对称差集`	^`只报了一个班，没同时报两个	==a ^ b
                                    结果：{'小明', '小李'}
